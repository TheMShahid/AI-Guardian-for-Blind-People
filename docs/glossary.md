# Project Glossary

| Attribute | Value |
|---|---|
| Document ID | GLO-001 |
| Version | 1.0 |
| Status | Initial terminology baseline |

| Term | Definition |
|---|---|
| Accessibility | Design enabling people with differing abilities to perceive, understand, navigate, and operate a system |
| AI inference | Applying a trained model to new input to produce output |
| Assistive technology | Technology intended to support functional capabilities or independence |
| Blind and low-vision users | People with varied visual abilities and access requirements |
| Confidence | A model-provided score/estimate; not automatically calibrated probability or guarantee |
| Device gateway | Software boundary for communication with connected hardware |
| Edge inference | Model processing on a local device near the data source |
| False negative | Relevant item/condition not detected by a model |
| False positive | Model reports an item/condition that is absent |
| Hazard | Potential source of harm |
| Human-centered design | Design informed by intended users' needs, contexts, and feedback |
| OCR | Optical Character Recognition; converting image text into machine-readable text |
| P0/P1/P2 | Requirement priority levels defined in SRS-001 |
| RTM | Requirements Traceability Matrix |
| Screen reader | Assistive software presenting interface content through speech or braille |
| Scene description | Generated summary of selected visual context; may be incomplete or incorrect |
| Verification | Evidence that a specified requirement has been met |
| Validation | Evidence that a product meets user needs in its intended context |
| Wearable | Device designed to be worn on the body |
