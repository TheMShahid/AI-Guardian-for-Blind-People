# Contributing

This repository is currently in a documentation and project-definition phase.

## Current scope
Contributions may improve requirements, architecture proposals, accessibility analysis, safety analysis, research governance, and technical decision records. Executable application code, AI implementation, firmware, and hardware build instructions are outside the currently authorized scope.

## Before proposing a change
- Read README.md and relevant controlled documents.
- Identify affected document IDs and requirements.
- Explain rationale and evidence.
- Identify safety, privacy, accessibility, and user impacts.
- Do not present assumptions as verified facts.
- Do not add secrets, private recordings, or unlicensed datasets.

## Documentation quality
Use clear technical language, stable IDs, testable requirements, explicit TBD markers, and links to related documents. Update RTM-001 when requirements change.

## Review
Material changes require consistency and impact review. Safety, privacy, or user-autonomy changes require explicit review.
