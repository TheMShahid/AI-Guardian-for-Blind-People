# AI Guardian for Blind People

An assistive technology project exploring accessible, AI-powered support for people who are blind or have low vision.

## Project status

**Status:** Initiation and documentation baseline  
**Current phase:** Project discovery, requirements definition, and feasibility planning  
**Repository:** [TheMShahid/AI-Guardian-for-Blind-People](https://github.com/TheMShahid/AI-Guardian-for-Blind-People)

The project is intended to evolve into a tested, integrated assistive solution spanning accessible user software, AI capabilities, and a wearable or portable device. Scope and technical choices remain provisional until validated through user research, requirements analysis, prototyping, and safety testing.

## Product direction

The solution will investigate a modular system that may include:
- An accessible mobile application and voice-first interaction.
- AI-assisted scene understanding, object recognition, and text reading.
- Context-aware audio or voice feedback.
- A connected wearable or portable device with camera and selected sensors.
- Embedded software, device connectivity, and application integration.

These are candidate capabilities, not claims of implemented or validated functionality.

## Safety statement

This project is supplementary assistive technology. It must not be represented as a replacement for a white cane, guide dog, orientation-and-mobility training, or other established mobility aids. Initial scope excludes autonomous street-crossing decisions and guaranteed obstacle avoidance.

## Development principles

1. Co-design and evaluate with blind and low-vision users.
2. Prioritize accessibility, dignity, privacy, and user control.
3. Validate performance in realistic environments, not only controlled demos.
4. Design for safe failure, including network, camera, sensor, and model failures.
5. Keep AI, application, and hardware components modular and testable.
6. Record assumptions and decisions; do not present unverified capabilities as facts.

## Current work boundary

The current authorized phase is documentation and project definition only. Application code, AI implementation, firmware, and physical hardware construction are not being undertaken in this phase. Future implementation requires a separately agreed start.

## Repository status

This repository contains initial planning documents. Requirements, architecture, technology selection, hardware, and release plans will be revised as evidence becomes available. Document status must be read alongside its assumptions and open questions.
