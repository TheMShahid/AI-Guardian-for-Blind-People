# AI Guardian for Blind People

An assistive technology project exploring accessible, AI-powered support for people who are blind or have low vision.

## Project status

**Status:** Initiation  
**Current phase:** Project discovery and requirements baseline  
**Repository:** [TheMShahid/AI-Guardian-for-Blind-People](https://github.com/TheMShahid/AI-Guardian-for-Blind-People)

The project is intended to evolve into a tested, integrated assistive solution spanning accessible user software, AI capabilities, and a wearable or portable device. The initial scope and technical choices are provisional until validated through user research, requirements analysis, prototyping, and safety testing.

## Product direction

The solution will investigate a modular system that may include:

- An accessible mobile application and voice-first interaction.
- AI-assisted scene understanding, object recognition, and text reading.
- Context-aware audio or voice feedback.
- A connected wearable or portable device with camera and selected sensors.
- Embedded software, device connectivity, and application integration.

These are candidate capabilities, not claims of implemented or validated functionality.

## Safety statement

This project is an assistive technology initiative. It must not be represented as a replacement for a white cane, guide dog, orientation-and-mobility training, or other established mobility aids. Any navigation-related feature must communicate uncertainty, handle failures safely, and undergo appropriate real-world evaluation before use.

## Development principles

1. Co-design and evaluate with blind and low-vision users.
2. Prioritize accessibility, dignity, privacy, and user control.
3. Validate performance in realistic environments, not only controlled demos.
4. Design for safe failure, including network, camera, sensor, and model failures.
5. Keep AI, application, and hardware components modular and testable.
6. Record assumptions and decisions; do not present unverified capabilities as facts.

## Repository status
